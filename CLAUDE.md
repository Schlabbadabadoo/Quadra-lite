# Quadra Lite

Lightweight, game-only fork of Quadra. Run the tests with:

    PYTHONPATH=launcher python3 -m unittest discover -s tests -p '*_test.py'

Install locally with `./install.sh`. The launcher needs Python 3, GTK 4 and
libadwaita. Runtime (Rosemary or Darling) is installed by the setup screen.
